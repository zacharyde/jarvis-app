# Jarvis - Privacy Policy

Last updated: November 1, 2026

Jarvis is a personal assistant used privately by its owner's household. It is not sold or offered to the public.

## What Jarvis accesses
- **Google Calendar:** reads calendars the owner has shared with Jarvis's own Google account (view-only), and writes only to Jarvis's own practice calendar.
- **Gmail (read-only):** reads message headers (sender, date, subject) of the owner's mailbox to spot schedule-related email. It never sends, deletes, labels or changes email.

## How data is used and stored
- Data is used only to plan the owner's own schedule and tasks.
- Data is stored on the owner's own computer, encrypted at rest; sign-in tokens are encrypted and never shared.
- Data is never sold, shared with third parties, or used for advertising.

## Google user data
Jarvis's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Removing access
The owner can remove Jarvis's access at any time at https://myaccount.google.com/permissions; Jarvis then deletes the related stored data.
